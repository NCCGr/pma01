How it works

One Worker, one connection

Users sign in with their own MySQL or MariaDB account. For each request the Worker opens a TCP connection with cloudflare:sockets, runs the page's queries on it and closes it when the response is sent.

Sessions in Durable Objects

Each session lives in its own Durable Object, the way PHP keeps a session file. The password cookie is encrypted with a key only that session holds, so logging out ends it everywhere. Sessions expire after 24 minutes idle, and their storage is deleted.

TLS to self-signed servers

MySQL servers are trusted by pinning their certificate's key. MariaDB servers prove their certificate after login, so a regenerated certificate keeps working and an impostor does not.

phpMyAdmin's own front end

Pages render phpMyAdmin's Twig templates, themes and JavaScript, unmodified. The PHP behind them is translated to TypeScript, class by class.

Take a sounding.

Deploy from GitHub, or set it up from a terminal. Both ask for a cookie key and the servers your users may sign in to. MySQL keys are pinned and MariaDB proves its certificate, so self-signed TLS just works.
